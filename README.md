# BioSense-AI

> IA confiável e segura aplicada à Saúde Digital: modelos de predição, detecção, classificação e regressão em dados biomédicos.

![Status](https://img.shields.io/badge/status-em%20desenvolvimento-yellow)
![UNIFEI](https://img.shields.io/badge/UNIFEI-Pouso%20Alegre-blue)

> Projeto científico e experimental. Nenhum modelo aqui substitui diagnóstico ou decisão médica.

## Sobre

O **BioSense-AI** é uma linha de pesquisa da UNIFEI (Campus Pouso Alegre) que desenvolve uma metodologia computacional **reprodutível, confiável e segura** para IA em dados biomédicos (ECG, EEG, sensores, voz e dados clínicos). Vigência: **nov/2026 a out/2029**.

## Estudos de caso

- **Epilepsia** (estudo inicial): detecção e previsão de crises
- **Doença de Parkinson**: classificação e estimativa de severidade
- **Doenças cardiovasculares**: detecção de alterações em ECG e risco

## Metodologia

Revisão da literatura → bases de dados e ética → análise exploratória → pré-processamento e características → modelos (baselines, ML clássico e redes neurais) → validação **por indivíduo** → interpretabilidade → robustez e cibersegurança → reprodutibilidade.

## Dados e ética

Uso prioritário de bases públicas, anonimizadas ou cedidas por parceiros. Dados brutos não são versionados neste repositório. Qualquer etapa com participantes depende de aprovação ética institucional.
